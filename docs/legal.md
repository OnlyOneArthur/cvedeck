# Data attribution and notices

CVEDeck is independent software and is not endorsed by CISA, NIST, the CVE Program, MITRE, or feed publishers.

## CVE Program

CVE records are retrieved from the CVE Program API. `CVE` and the CVE logo are registered trademarks of The MITRE Corporation. CVE data use is subject to the CVE Program terms published at https://www.cve.org/Legal/TermsOfUse .

## NVD

This product uses data from the NVD API but is not endorsed or certified by the NVD. See https://nvd.nist.gov/developers/terms-of-use . An API key is optional and remains environment-only.

## CISA KEV

Known Exploited Vulnerabilities metadata comes from CISA: https://www.cisa.gov/known-exploited-vulnerabilities-catalog . A KEV entry indicates evidence of active exploitation but does not determine local asset impact.

## News feeds

CVEDeck consumes publisher-provided RSS/Atom metadata from Krebs on Security, The Hacker News, and SecurityWeek. It does not fetch article pages or republish full articles. Titles, feed excerpts, and links remain attributable to their publishers and subject to publisher terms. Users should review those terms before redistributing stored metadata.
